Quick start

설치와 실행

Rust 1.95.0이 필요합니다. 저장소를 받은 뒤 워크스페이스 루트에서 실행하세요.

Terminal
$ cargo run -p sampler-tui
i
먼저 이것만 기억하세요

?는 현재 화면 도움말, :는 명령어 입력, Tab은 작업 화면 전환입니다.

다른 실행 모드

cargo run -p sampler-tui -- open path/to/project저장한 프로젝트를 바로 열기
cargo run -p sampler-tui -- play path/to/sample.wav샘플 디코딩과 출력을 진단
cargo run -p sampler-tui -- export path/to/project 1 output.wav화면 없이 패턴 1을 WAV로 렌더링

Perform

패드 연주

키보드 왼쪽 4 × 4 영역이 현재 뱅크의 16개 패드입니다. 방향키로 선택하고 Enter로 선택 패드를 연주할 수도 있습니다.

BANK A · PADS 01–16

[O]

OneShot

한 번 누르면 끝까지 재생됩니다. 재생 중 같은 패드를 누르면 멈추고, 다시 누르면 처음부터 재생됩니다.

[G]

Gate

패드를 누르는 동안만 재생됩니다. H를 함께 눌러 소리를 계속 유지할 수 있습니다.

[L]

Loop

패드가 활성화된 동안 지정한 구간을 반복합니다.

!
Space는 패드 재생 키가 아닙니다

현재 패턴의 재생·정지를 전환합니다. 선택한 패드는 Enter 또는 해당 패드 키로 재생하세요.

04

Import

샘플 불러오기

  1. 1
    목적지 패드 선택

    패드 키 또는 방향키로 샘플을 넣을 자리를 선택합니다.

  2. 2
    파일 선택기 열기

    Shift+X 또는 L을 누릅니다. :load path/to/sample.wav도 사용할 수 있습니다.

  3. 3
    파일 선택

    WAV, AIFF, FLAC, MP3를 지원합니다. 원본 파일은 수정하지 않습니다.

  4. 4
    패드로 확인

    상태가 READY가 되면 해당 패드 키를 눌러 들어봅니다.

✓
녹음 전에 PEAK를 확인하세요

말하거나 손뼉을 칠 때 PEAK가 올라가야 합니다. 완전한 무음 입력은 기존 패드를 보호하기 위해 설치되지 않습니다.

⌘
macOS 클램셸 모드

MacBook 덮개를 닫으면 내장 마이크가 무음이 될 수 있습니다. 외장 또는 iPhone 연속성 마이크를 기본 입력으로 선택하고 앱을 다시 시작하세요. 실행 터미널에도 시스템 설정 → 개인정보 보호 및 보안 → 마이크 권한이 필요합니다.

06

Resample

연주를 다시 샘플로

리샘플링은 패드, 패턴, 레벨, 팬, 딜레이와 리버브를 모두 거친 최종 스테레오 출력을 선택한 패드에 녹음합니다.

  1. 1
    빈 패드 또는 교체할 패드를 선택
  2. 2
    Ctrl+S 다음 R

    리샘플 캡처가 시작됩니다.

  3. 3
    패드나 패턴을 연주

    마스터에서 들리는 결과가 그대로 들어갑니다.

  4. 4
    Enter로 완료

    새 샘플이 선택한 패드에 설치됩니다.

Projects

저장하고 다시 열기

프로젝트는 설정을 TOML에 저장하고 사용 중인 오디오를 프로젝트의 audio/ 디렉터리로 복사합니다. 전체 폴더를 옮겨도 오디오 참조가 유지됩니다.

Command palette
# 처음 저장
:save-as path/to/my-project

# 이후 저장 / 다른 프로젝트 열기
:save
:open-project path/to/another-project

# 현재 패턴 한 루프 내보내기
:export path/to/output.wav
!
진행 중인 작업 보호

미완성 녹음, 샘플 편집 초안, 저장하지 않은 변경이 있으면 프로젝트 열기나 종료 전에 처리 방법을 묻습니다. 복구 화면에서는 R 복원 · D 폐기 · C 취소를 사용합니다.

11

MIDI

MIDI 컨트롤러 연결

MIDI Note 36–51은 현재 뱅크의 패드 1–16에 연결됩니다. 벨로시티, 채널 필터, 뱅크별 Learn 매핑을 지원합니다.

:midi-ports사용 가능한 입력 포트와 번호 확인
:midi-connect 00번 포트에 연결
:midi-channel omni모든 채널 수신, 또는 1–16 지정
:midi-learn선택한 패드의 Learn 대기
:midi-unmap선택 패드의 매핑 제거
:midi-reset-bank현재 뱅크 매핑 초기화
:midi-disconnect현재 포트 연결 해제

Reference

명령어 빠른 참조

:를 눌러 명령 팔레트를 열고 아래 명령을 입력합니다. 경로에 공백이 있으면 전체 나머지를 경로로 사용하거나 따옴표로 감쌀 수 있습니다.

파일과 프로젝트

:load [path]:save:save-as <directory>:open-project <directory>:export <file.wav>

선택과 재생

:bank <A..J>:select <1..16>:play:stop:stop-all

패턴

:pattern <1..16>:tempo <20..300>:bars <n>:resolution <value>:swing <50..75>:quantize <0..100>:record:clear-pattern

샘플과 캡처

:trim-start <frame>:trim-end <frame>:normalize <on|off>:reverse <on|off>:pitch <-24..24>:mode <oneshot|gate|loop>:apply-sample:undo-sample:record-input:resample:capture-stop:capture-cancel

패드 믹스

:pad-level <-60..6>:pad-pan <-1..1>:pad-mute <on|off>:pad-choke <off|1..16>:delay-send <0..1>:reverb-send <0..1>

마스터 이펙트

:master-level <-60..6>:delay-enable <on|off>:delay-time <ms>:delay-feedback <0..0.95>:delay-return <-60..6>:reverb-enable <on|off>:reverb-room <0..1>:reverb-damping <0..1>:reverb-return <-60..6>
13

Troubleshooting

막혔을 때

녹음 PEAK가 계속 0입니다

운영체제의 기본 입력 장치와 터미널 마이크 권한을 확인한 뒤 앱을 다시 시작하세요. MacBook 덮개가 닫혀 있으면 내장 마이크 대신 외장 또는 iPhone 마이크를 사용해야 합니다.

PEAK는 움직이는데 녹음한 소리가 들리지 않습니다

Enter로 녹음을 마무리한 후 목적지 패드 키를 누르세요. Space는 선택 패드가 아니라 패턴을 재생합니다. 출력 장치와 시스템 볼륨도 확인하세요.

패드를 다시 눌렀는데 동작이 헷갈립니다

OneShot 패드는 재생 중 다시 누르면 정지합니다. 그 다음 누름부터 새로 재생됩니다. 확실하게 정지하려면 Shift+해당 패드, 전체 정지는 Shift+Esc를 사용하세요.

Audio device connected에서 멈춘 것처럼 보입니다

터미널 크기가 최소 80 × 24인지 확인하세요. 오디오 장치 변경 뒤에는 앱을 다시 시작하고, 장치 오류 화면에서는 Ctrl+R로 오디오 연결을 재시도할 수 있습니다.

패드에 있던 소리를 지우고 싶습니다

현재 버전은 빈 파일을 덮어쓰는 방식 대신 새 샘플로 교체하는 흐름을 중심으로 합니다. 재생만 멈추려면 Shift+패드를 사용하세요.
