Quick start

Install and run

sampler-tui uses Rust 1.95.0. From the root of a checked-out repository, run:

Terminal
$ cargo run -p sampler-tui
i
Remember these three controls

? opens contextual help, : opens the command palette, and Tab changes workspaces.

Other launch modes

cargo run -p sampler-tui -- open path/to/projectOpen a saved project directly
cargo run -p sampler-tui -- play path/to/sample.wavDiagnose sample decoding and output
cargo run -p sampler-tui -- export path/to/project 1 output.wavRender pattern 1 to WAV without the TUI

BANK A · PADS 01–16

[O]

OneShot

One press plays the sample to its end. Press the same active pad to stop it; press again to start from the beginning.

[G]

Gate

The sample plays only while the pad is held. Hold H with a Gate pad to keep it active.

[L]

Loop

The selected sample region repeats while the pad remains active.

!
Space does not play the selected pad

It starts or stops the current pattern. Use Enter or the pad's own key to play the selected pad.

04

Import

Import a sample

  1. 1
    Select a destination pad

    Use a pad key or the arrow keys to choose where the sample will go.

  2. 2
    Open the file picker

    Press Shift+X or L. You can also enter :load path/to/sample.wav.

  3. 3
    Choose a file

    WAV, AIFF, FLAC, and MP3 are supported. The source file is never modified.

  4. 4
    Check the pad

    When its state is READY, press the pad key to hear it.

Capture shortcuts

Ctrl+S → IStart recording the default input
Ctrl+S → RStart resampling the master output

Ctrl+S → SStop and finalize the active take
Ctrl+S → CCancel the active take

✓
Check PEAK before recording

PEAK should move when you speak or clap. A completely silent input is rejected so it cannot replace the existing pad.

⌘
macOS clamshell mode

The built-in microphone may return silence while a MacBook lid is closed. Select an external or iPhone Continuity microphone as the default input, then restart sampler-tui. The launching terminal also needs permission under System Settings → Privacy & Security → Microphone.

06

Resample

Turn a performance into a sample

Resampling records the final stereo master after pads, patterns, levels, pan, delay, and reverb, then installs the result on the selected pad.

  1. 1
    Select an empty pad or one to replace
  2. 2
    Press Ctrl+S, then R

    Master-output capture begins.

  3. 3
    Play pads or a pattern

    Everything audible at the master is recorded.

  4. 4
    Press Enter to finish

    The new sample is installed on the selected pad.

10

Projects

Save and reopen

A project stores its configuration in TOML and copies used audio into its own audio/ directory. Move the complete folder and its audio references remain valid.

Command palette
# First save
:save-as path/to/my-project

# Save again / open another project
:save
:open-project path/to/another-project

# Export one loop of the current pattern
:export path/to/output.wav
!
Your work is protected

If a capture, sample-edit draft, or unsaved project change is active, opening another project or quitting asks how to resolve it. On recovery screens use R to restore, D to discard, or C to cancel.

11

MIDI

Connect a MIDI controller

MIDI Notes 36–51 map to pads 1–16 in the current bank. Velocity, channel filtering, and per-bank Learn mappings are supported.

:midi-portsList available input ports and indexes
:midi-connect 0Connect to port 0
:midi-channel omniReceive every channel, or specify 1–16
:midi-learnArm Learn for the selected pad
:midi-unmapRemove the selected pad mapping
:midi-reset-bankReset mappings for the current bank
:midi-disconnectDisconnect the current port

13

Troubleshooting

When something goes wrong

Recording PEAK stays at 0

Check the operating system's default input and your terminal's microphone permission, then restart sampler-tui. With a closed MacBook lid, use an external or iPhone microphone instead of the built-in input.

PEAK moves, but the recording is silent on playback

Press Enter to finalize the take, then press its destination pad. Space plays the pattern, not the selected pad. Also check the output device and system volume.

Pressing the same pad again is confusing

Pressing an active OneShot pad stops it. The following press starts it again from the beginning. Use Shift+pad for an explicit stop or Shift+Esc to stop everything.

The screen appears stuck at “Audio device connected”

Ensure the terminal is at least 80 × 24. Restart after changing audio devices, or press Ctrl+R on a device error screen to retry the audio connection.

I want to clear a pad

The current workflow replaces pads with new samples rather than writing an empty file. To stop playback without replacing the sample, press Shift+pad.
